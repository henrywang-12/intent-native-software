# The agent as a new distribution gatekeeper

*Platform power companion · 4 November 2026 · AI-assisted analytical working note.*

When a user asks an agent to choose a service, the recommendation interface may shrink from many visible options to one executed result. This could move bargaining power from an app catalog to the system that interprets intent and selects providers.

**Hypothesis.** The agent operator can influence supplier demand through eligibility rules, default choices and ranking. A nominally open API ecosystem can remain economically concentrated if a small number of assistants route most transactions.

Apple's published review guidelines show how platform participation can be governed explicitly. The analogous agent problem adds another layer: even an admitted provider may receive no traffic if routing rules favor other suppliers.

**Proposed disclosure.** Show the binding constraints, whether sponsorship influenced selection and how the user can choose an alternative. Preserve an auditable decision record without exposing unrelated private context. Ranking transparency need not reveal exploitable fraud controls or private model internals.

**Experiment.** Hold supplier quality constant while varying sponsorship, default status and user ability to inspect alternatives. Measure price paid, fulfillment quality and supplier demand concentration. Include users who override the recommendation.

**Counterargument.** A good default can save substantial effort and outperform manual search. The test is whether the default serves the user's stated objective and remains contestable. A universal requirement to inspect every option would destroy much of the product's value.

The future bottleneck may be trusted allocation of intent, not ownership of the most software screens.

# F02 · Task portability moves beyond chat export

**Issued:** 2026-11-01 · **Resolve by:** 2029-12-31 · **Status:** open
**Working confidence:** low, qualitative and uncalibrated. These are editorial hypotheses, not measured probabilities or promises.

## Event

At least two independently governed hosts demonstrate transfer of a pending or indeterminate task with preserved outcome semantics, and publish a common exchange specification and runnable example.

## Mechanism

Useful exit will require commitments and uncertainty to move, not merely conversation text.

## Qualification boundary

The receiving host must explain the state and continue a supported task without importing active credentials. A completed transcript does not qualify.

## Resolution procedure

Use public implementations and a documented independent reproduction. Record any manual translation required. Search the named product documentation where applicable, scholarly indexes and public repositories. Save the evidence and search date. At the deadline mark true if qualifying public evidence exists, false only after a documented search finds none, and unresolved if access or interpretation prevents adjudication. Keep the original wording when updating status.

## Evidence against the mechanism

If exports remain static transcripts or host-specific archives with no demonstrated continuation, the prediction fails.

The event is deliberately narrower than the mechanism. Its occurrence would not establish market-wide adoption, causality or Walify's success. Forecasts share assumptions and should not be multiplied as independent probabilities.

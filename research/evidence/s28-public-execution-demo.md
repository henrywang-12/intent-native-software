# S28 · Intent-Native Software: public execution demo

**Source:** Intent-Native Software contributors · baseline commit 4a984b5; checked 2026-11-01
**Evidence type:** public implementation and tests
**Accessed:** 2026-11-01 · [Original source](https://github.com/henrywang-12/intent-native-software/tree/4a984b552067bcc141d18052d304a08f6111ab52/demo)

## What the source supports

The repository implements exact-request approval, revocation, pre-dispatch cancellation, a simulated provider, reconciliation and receipts in local Python and SQLite. Its 24 baseline tests passed in this review.

## Boundary of the evidence

This is a single-process teaching implementation, without a model planner or external integrations. It is not evidence about deployed Walify capabilities or end-user adoption.

## Use in this study

It gives the paper an inspectable implementation boundary. Walify is discussed through the author-stated human-and-agent software vision, without private implementation claims.

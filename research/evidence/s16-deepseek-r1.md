# S16 · DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

**Source:** DeepSeek-AI · 2025-01-22; v1 used
**Evidence type:** model developer technical report
**Accessed:** 2026-11-01 · [Original source](https://arxiv.org/html/2501.12948v1)

## What the source supports

The report distinguishes R1-Zero's reinforcement-learning setup from R1's multistage training and cold-start data, and describes distilled smaller models.

## Boundary of the evidence

It does not show that base-model training needs no data or that reasoning performance transfers unchanged to real service execution. Developer-reported results are not this repository's replications.

## Use in this study

Reasoning methods can diffuse into smaller deployable models. Forecast the economics of a capable portfolio rather than assuming one permanently dominant model.

This note is an editorial evidence assessment, not an independent replication or an endorsement by the cited authors.

# S20 · The Open Source AI Definition 1.0

**Source:** Open Source Initiative · version 1.0; accessed 2026-11-01
**Evidence type:** definition
**Accessed:** 2026-11-01 · [Original source](https://opensource.org/ai/open-source-ai-definition)

## What the source supports

The definition addresses freedoms to use, study, modify and share, with requirements concerning parameters, code and training-data information.

## Boundary of the evidence

Downloadable weights alone do not establish conformity with this definition. Access, license restrictions, reproducibility and actual ability to operate the model must be checked separately.

## Use in this study

The paper uses 'open weights' when only weight availability is established. Openness is a vector of practical rights and resources, not a binary synonym for inexpensive inference.

This note is an editorial evidence assessment, not an independent replication or an endorsement by the cited authors.

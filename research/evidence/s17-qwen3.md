# S17 · Qwen3 Technical Report

**Source:** Yang and colleagues · 2025-05-14
**Evidence type:** model developer technical report
**Accessed:** 2026-11-01 · [Original source](https://arxiv.org/abs/2505.09388)

## What the source supports

The report describes dense and mixture-of-experts models, thinking and non-thinking modes, and an inference thinking-budget mechanism.

## Boundary of the evidence

This is evidence about the reported family, not a claim that it remains the latest Qwen release or that longer thinking always improves outcomes.

## Use in this study

A service can select reasoning effort by task. The paper's routing experiment separates model choice, fallback expense and verified task quality.

This note is an editorial evidence assessment, not an independent replication or an endorsement by the cited authors.

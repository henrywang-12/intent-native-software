# S24 · AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents

**Source:** Debenedetti and colleagues · 2024; v3 used
**Evidence type:** security evaluation research
**Accessed:** 2026-11-01 · [Original source](https://arxiv.org/html/2406.13352v3)

## What the source supports

AgentDojo separates legitimate-task utility from attacker goals and supports adaptive attacks in stateful tool environments. Deterministic state checks help avoid a compromised language-model judge.

## Boundary of the evidence

A finite suite does not certify general safety. Blocking every action can reduce attack success while destroying usefulness; report both dimensions.

## Use in this study

The study's proposed tests measure authorized completion and unintended effects separately. Trusted policy and receipt validation should not depend on obeying retrieved text.

This note is an editorial evidence assessment, not an independent replication or an endorsement by the cited authors.

# P20 · Does repeat use reflect durable value?

**Status: proposed protocol; not run.** The local analytical models are separate artifacts.

## Estimand

Estimate retention and net benefit after novelty and subsidies decline.

## Design and control

Propose an opt-in study of recurring bounded tasks with a conventional baseline and explicit observation windows. Fix cohort entry rules before analysis.

## Outcomes

Track completed useful tasks, supervision minutes, support cost, provider participation and repeat voluntary use.

## Confounds and boundaries

Separate subsidy effects, novelty, survivor bias and task selection. Report all enrolled users and provider attrition, not only active survivors.

## Decision and reporting rule

The marketplace thesis gains support only if repeat value and viable operating economics coexist. This repository contains no such user study or adoption claim.

Record assignment, exclusions, all attempts, versions and budgets. Choose sample size and a stopping rule before confirmatory data collection; publish null and adverse results. Live-service or participant studies require an appropriate separate study setup.

These sources motivate the design; they did not run this proposed study.

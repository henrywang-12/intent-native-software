# P19 · Can different users exercise the same control?

**Status: proposed protocol; not run.** The local analytical models are separate artifacts.

## Estimand

Assess whether shared task state supports equivalent understanding across interface modes.

## Design and control

Test keyboard, screen-reader-compatible text and visual review modes with appropriately recruited participants and synthetic tasks.

## Outcomes

Measure task completion, authority comprehension, navigation burden and recovery access. Report results by mode with uncertainty.

## Confounds and boundaries

Automated accessibility checks do not substitute for participant evidence. Preserve identical task semantics across modes.

## Decision and reporting rule

Do not claim universal accessibility from one mode. Resolve critical control failures before interpreting average convenience gains.

Record assignment, exclusions, all attempts, versions and budgets. Choose sample size and a stopping rule before confirmatory data collection; publish null and adverse results. Live-service or participant studies require an appropriate separate study setup.
